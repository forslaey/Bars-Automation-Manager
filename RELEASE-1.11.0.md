# Менеджер автоматизации Барс 1.11.0

Первый выпуск новой линейки.

Скачай `Bars.Automation.Manager.1.11.0.exe` и запусти. Внутри одной программы доступны службы, библиотеки, SQL Server и SSMS, программы Барс, службы и агенты, прикладные программы, утилиты и прошивки, настройки Windows и сбор логов.

Папка комплекта по умолчанию — `C:\Менеджер автоматизации Барс`. Выбрать другую папку и скачать нужные разделы можно через «Скачать комплект». Если Windows не хватает .NET Framework 4.8, его предложит запускатель.

Если у тебя тестовая сборка 2.3.x, скачай 1.11.0 вручную. Автоматическая проверка сравнивает числовые версии.

EXE имеет подпись Authenticode с меткой времени. Сертификат издателя самоподписанный. Windows доверяет ему после настройки доверия в организации.
