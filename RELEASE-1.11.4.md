# Менеджер автоматизации Барс 1.11.4

- В «Программах Барс» появилось подключение к базе данных. Менеджер ищет SQL Server, показывает доступные базы и сохраняет проверенные настройки в конфиг выбранной программы.
- DevExpress 15.1.4 и 22.1.4 устанавливаются отдельно из общего комплекта. При удалении менеджер снимает регистрацию, очищает папку версии и сохраняет общие сборки до удаления последней версии.
- Для библиотек со статусом «Нужна проверка» открывается окно действий. Поддерживаемые пакеты из локальной папки «_libraries» обнаруживаются при повторной проверке.
- В модуле SQL Server и SSMS улучшено распознавание автономного комплекта SSMS. Кнопка «Подготовить свой набор» перенесена в нижнюю панель.
- Временная папка загрузок очищается после завершения или отмены очереди. Встроенная инструкция обновлена.
