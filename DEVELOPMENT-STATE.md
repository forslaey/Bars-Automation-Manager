# Состояние разработки

Стартовая версия — 1.11.0. Путь комплекта по умолчанию — `C:\Менеджер автоматизации Барс`. Запускатель ищет установщик .NET Framework в `_barsmanager`.

Файл сборки и вложение GitHub Releases используют формат `Bars.Automation.Manager.<версия>.exe`. Внешний Rust-запускатель, встроенный менеджер и помощники подписываются одним сертификатом.

Рабочие инструкции: [разработка](docs/DEVELOPMENT.md), [руководство пользователя](docs/USER-GUIDE.md), [правила проекта](AGENTS.md).
