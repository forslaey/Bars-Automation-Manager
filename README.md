# Менеджер автоматизации Барс

Автоматизированная установка, обслуживание и настройка программного обеспечения.

**[Скачать версию 1.11.2](https://github.com/forslaey/Bars-Automation-Manager/releases/tag/v1.11.2)** · [Руководство пользователя](docs/USER-GUIDE.md) · [Что нового](CHANGELOG.md)

Скачай `Bars.Automation.Manager.1.11.2.exe` и запусти. Устанавливать сам менеджер не требуется. Для локальных пакетов используется `C:\Менеджер автоматизации Барс` или другая папка, которую ты выберешь в «Скачать комплект».

| Модуль | Для чего нужен |
|---|---|
| Первичные системные настройки | Проверка и применение настроек Windows |
| Менеджер библиотек | Библиотеки, компоненты Windows и установщики .NET |
| Менеджер служб | Установка и управление службами, диагностика и сбор логов |
| SQL Server и SSMS | Загрузка наборов, распаковка и запуск мастеров |
| Программы Барс | Загрузка и тихая установка поддерживаемых программ |
| Службы и агенты Барс | Загрузка и распаковка архивов |
| Прикладные программы | Chrome, Notepad++, 7-Zip, AnyDesk и RuDesktop |
| Утилиты и прошивки | Скачивание, распаковка, создание ярлыков и удаление |
| Логи программ | Сбор журналов в ZIP |

«Скачать комплект» получает выбранные разделы с Яндекс Диска или Google Диска. Если Windows не хватает .NET Framework 4.8, запускатель ищет установщик в `_barsmanager` или предлагает скачать его отдельно.

### Настройка рабочих компьютеров

При сборке из исходников без внутренних настроек для автоматического входа в Bars.Release задай переменную среды Windows
`BARS_RELEASE_PASSWORD` с паролем выделенной учётной записи каталога `service`.
Для чекбокса «Стандартный пароль Барса» задай `BARS_REMOTE_STANDARD_PASSWORD`
с согласованным паролем AnyDesk и RuDesktop. Менеджер читает переменные процесса,
а если их нет — переменные уровня компьютера. После изменения переменных
пользователя перезапусти менеджер из сеанса, в котором они уже доступны.

Для внутреннего выпуска Build-OneFileRust.ps1 принимает -EmbedWorkstationSettings и читает обе переменные из процесса сборки. Такой EXE предназначен для закрытого распространения.
Для приватного репозитория скачивай выпуск вручную через GitHub с учётной записью, которой выдан доступ. Менеджер проверяет обновления без авторизации GitHub.
