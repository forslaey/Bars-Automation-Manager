# История выпусков

## 1.11.0

Первый выпуск Менеджера автоматизации Барс.

- Девять модулей в лаунчере, встроенная инструкция и фирменные диалоги выбора пути.
- Отдельные модули для программ Барс, служб и агентов, SQL Server и SSMS.
- Загрузка комплектов с Яндекс Диска и Google Диска. Корневая папка по умолчанию — `C:\Менеджер автоматизации Барс`.
- Поддержка пакетов Visual C++ в формате 7z, установка библиотек и обновление установщиков .NET.
- Сбор логов служб и программ, диагностика отклика, распаковка утилит и выбор ярлыков.
- Автообновление с GitHub и переход к репозиторию из строки версии в окне «О программе».
- Один EXE с новым сертификатом подписи кода.
